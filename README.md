# Incrementing Counter

Bu proje, web sayfasında sayıları **animasyonlu şekilde artan sayaçlarla** göstermeyi amaçlar.  
Örneğin sosyal medya takipçi sayıları, abone sayıları veya istatistikler dinamik olarak artarak kullanıcıya sunulur.

<img width="1500" height="737" alt="image" src="https://github.com/user-attachments/assets/6680897d-6bc5-4647-9843-adae945c824a" />


##  Özellikler
- Sayıların sıfırdan hedef değere kadar artması  
- Akıcı ve görsel olarak hoş animasyon  
- İstenilen metin ve ikonlarla özelleştirilebilir  
- HTML, CSS ve JavaScript ile geliştirilmiş  

##  Kullanılan Teknolojiler
- **HTML5** → Yapı için  
- **CSS3** → Stil ve düzen için  
- **JavaScript (ES6)** → Sayaçların artış mantığı için
